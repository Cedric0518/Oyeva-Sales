# Atlas General Store: sample data for Oyeva Sales

Fictional data. Atlas General Store is an invented Ontario general retailer: four stores (Toronto - Queen Street, Mississauga, Hamilton, Ottawa) and an online shop, selling groceries, household supplies, health and beauty, office and school supplies, seasonal items, toys and games, to households and business accounts. Period: September 1, 2024 to August 31, 2026.

Generated by `make_atlas.py` (seed 20261031). Reference answers by `atlas_answers.py`. To
regenerate, from the repository root, with the versions pinned in `requirements.txt`:

```bash
python evals/data/atlas/make_atlas.py evals/data/atlas
python evals/data/atlas/atlas_answers.py evals/data/atlas
git diff --stat evals/data/atlas    # the CSV and the JSON files should not change
```

The company notes (`atlas_context.*`) are not generated by the script: the `.md` was written
separately, and the `.docx` and `.pdf` are conversions of it.

## Definitions used by the oracle (certified metrics v1)

- Sales: sum of `amount`, returns included, file taken as-is (duplicates are not removed silently; values without them are also given).
- Rows dated after August 31, 2026 are ignored.
- Customer metrics ignore "Walk-in". Name variants are not merged by the oracle (the check reports them).
- Lost customer: bought in the reference period, not in the comparison period. New: the reverse. Retained: both.
- Average basket: sales / number of distinct `order_id` with a positive amount.
