===== Run 3 =====
--- answer ---
I found the top 3 customers in 2025 by total sales amount.

### Code run
```python
import pandas as pd

path='/mnt/data/assistant-HMX9DEaWdLgVDrtKen5KEi-atlas_sales.xlsx'
df = pd.read_excel(path, sheet_name='Orders', parse_dates=['order_date'])

# filter 2025
f = df[df['order_date'].dt.year == 2025].copy()

# aggregate by customer sales amount
cust = (f.groupby('customer', as_index=False)
          .agg(total_amount=('amount','sum'), orders=('order_id','nunique'))
          .sort_values(['total_amount','orders'], ascending=[False, False]))

print(cust.head(10).to_string(index=False))
```

### Result
1. **Walk-in** — **$222,151.03** across **5,926** orders  
2. **Bayfront Elementary School** — **$25,266.63** across **52** orders  
3. **Pinecrest Seniors Residence** — **$19,738.21** across **40** orders
